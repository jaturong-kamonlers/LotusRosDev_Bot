ที่มา: –
ล้อ เป้า rpm · ค้าง ms
rpm (เฉลี่ย 100 ms):เป้า (เส้นประ ทรงขั้นบันได)ซ้ายขวา · เส้นจาง = รอบก่อน
PWM ที่ PID สั่ง (0–1023)
รอบค่า PID (ซ้าย / ขวา)ล้อขึ้นถึง 90%พุ่งเกินขาดจากเป้านิ่งใน ±5%แกว่ง
วิธีจูน (ล้อลอย)
  1. ทดสอบค่าเดิมก่อน 1 รอบ (60 rpm ทั้งสองล้อ) ดูกราฟ
  2. ขึ้นช้า / ไปไม่ถึง → เพิ่ม Kp ทีละ ~20% · สั่น/แกว่งรอบเป้า → ลด Kp
  3. ค้างต่ำกว่าเป้า (ขาดจากเป้า > 3%) → เพิ่ม Ki · พุ่งเกินมาก (> 10%) → ลด Ki
  4. พุ่งเกินแม้ Ki พอดี → เพิ่ม Kd ทีละน้อย · ถ้ากราฟ PWM กระตุก → ลด Kd
  5. ให้สองล้อมีกราฟใกล้กัน (หุ่นจะออกตัวตรง) · ลองทั้ง 30, 60, 90 rpm และค่าติดลบ (ถอย)
  6. พอใจแล้วกด 💾 บันทึกลงบอร์ด (ใช้ทันทีทั้งโหมด ROS2 แม้ยังไม่แก้โค้ด) แล้วคัดลอกบรรทัดด้านล่างไปใส่ include/lotusrosbot_config.h เพื่อเก็บถาวร

📖 อ่านกราฟ step ให้เป็น — กราฟที่ดีหน้าตาแบบไหน● กำลังทำงาน

ดูอะไรกราฟที่ดี (เป้าของหุ่นตัวนี้)ถ้าไม่ได้ ให้ปรับ
ขึ้นถึง 90% ของเป้า≤ 0.3 วินาทีช้า → เพิ่ม Ki (ตัวหลัก) · Kp ช่วยช่วงแรก
พุ่งเกินเป้า≤ 5% (ไม่เกิน 10%)เกินมาก → ลด Ki หรือเพิ่ม Kp เล็กน้อย
ขาดจากเป้าตอนนิ่ง≤ 2%ค้างต่ำกว่าเป้า → เพิ่ม Ki (ถ้า Ki = 0 จะไม่มีวันถึงเป้า)
นิ่งในช่วง ±5%≤ 0.4 วินาที · ไม่แกว่งขึ้นลงแกว่งรอบเป้า → ลด Ki / เพิ่ม Kd เล็กน้อย
กราฟ PWMขึ้นเร็วแล้วเรียบ · ไม่ชนเพดาน 1023 นาน · ไม่กระตุกกระตุก/ชนเพดาน → ลด Kp · เป็นหนาม → ลด Kd
ล้อซ้ายเทียบขวาเส้นซ้อนกันต่างกัน → จูนแยกล้อ (ปลดติ๊ก "ใช้ค่าเดียวกัน")

ลำดับที่แนะนำ: ① ทดสอบค่าเดิม → ② เพิ่ม Ki จนขึ้นเร็วแต่เกินไม่ถึง 10% → ③ ปรับ Kp ให้เกินน้อยลง → ④ Kd 0–0.5 ให้นิ่งเร็ว → ⑤ ลอง 30 / 90 / −60 rpm ต้องดีทุกค่า → ⑥ ทดสอบวิ่งบนพื้นจริง (มีภาระ) แล้วค่อยบันทึก · ค่าที่ได้วันนี้: เดิม 0.35/0.40/0.10 ขึ้นถึง 90% ใน 1.0 วิ → 4 / 2.0 / 0.2 ใน 0.24 วิ

ระบบ ROS2: –
    

  
เปิดระบบ = บอร์ดรีบูตเข้าโหมด ROS2 → เปิด agent + bringup (LiDAR, odom) ให้เอง ~20 วินาที · หุ่นต้องจอดนิ่งช่วงเปิด · ค่า PID ที่ใช้ = ค่าที่ "บันทึกลงบอร์ด" (ถ้าไม่ได้บันทึก = ค่าในโค้ด) · ทดสอบเสร็จกด "ปิดระบบ ROS2" ก่อนกลับมาใช้การ์ด 1–10
